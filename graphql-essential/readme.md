### What is GraphQL ?
GraphQL is query language for any kind of APIs and is able to full fill any queries across multiple databases. So in other words, its not a server or a database, Its a query language and server-side runtime for APIs created my Meta.

The main benefit of using it that you can ask for exactly what you want and you will get those results and nothing else.

### Core Feature:
- **Exact Data Fetching:** Clients request only the specific fields they need, which prevents getting too much or too little data.

- **Single Endpoint:** All requests go to one URL instead of multiple separate routes.

- **Strongly Typed Schema:** A strict system defines data types and relationships so clients and servers agree on structure.

### Main Operation:
- ***Queries:*** Read or fetch data from the server.
- ***Mutations:*** Write, update, or delete data on the server.
- ***Subscriptions:*** Listen for real-time updates through WebSockets
